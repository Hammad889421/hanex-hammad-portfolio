# HANEX Technologies — M. Hammad Hussain Portfolio

A responsive, animated personal portfolio and founder showcase for M. Hammad Hussain.

## Run locally
This is a static website and does not require npm or a build step.

1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. For hosting, upload the complete folder to Netlify or import it into a GitHub repository and deploy with Vercel.

## Files
- `index.html` — all portfolio sections and content
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation, scroll reveals, skill animation, project detail modals
- `assets/` — supplied portrait and HANEX branding images
